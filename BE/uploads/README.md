# Kho ảnh

- `avatars/`: ảnh đại diện.
- `products/`: ảnh sản phẩm.
- `forum/`: ảnh diễn đàn.

Ảnh được phục vụ tại `/uploads/<thư-mục>/<tên-file>`. Ví dụ ảnh sản phẩm dùng tạm: `/uploads/products/7e4cb1d424ce6a785ae006361dd1b130.jpg`.

Hiện đặt file trực tiếp vào thư mục; chưa có API nhận file upload. Các thư mục này dành cho ảnh công khai, không đặt thông tin riêng tư tại đây.
